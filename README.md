# Vibe Dialer

Separate dialer app in Vibe style (liquid glass / blur / Orbit-inspired layout).

## MVP in this scaffold
- Default dialer role request on start
- Phone / Contacts / Settings bottom navigation with movable bubble
- Floating keypad, collapsible into icon
- Right-hand Orbit mode
- InCallService + InCallActivity with movable in-call controls
- GitHub Actions build workflow

## Build
Built by GitHub Actions (`gradle assembleDebug`). No local Android SDK required.
